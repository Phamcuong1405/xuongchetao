D3a — pages_messaging

FBAUTO is the internal sales desk for our Facebook Page "Xuong Bom MINI"
(Page ID 1242996232237252). When a person messages the Page, our webhook
receives the event and we send an automated + agent-assisted reply with an
order button and hotline, strictly inside the standard 24-hour messaging
window, so the customer can place a COD product order. We do not message
people who have not contacted the Page.

D3b — business_management

Required dependency so a Page admin can grant this app access to Pages they
manage (together with pages_show_list and pages_messaging) and obtain a Page
access token for our server. The app is owned by verified Business Fovimarlo.

D3c — pages_manage_metadata

Used only to subscribe our Page to webhook fields (messages,
messaging_postbacks, feed) so the backend receives Messenger events and Page
feed comment events in real time.

D3d — pages_show_list

Used so the Page admin can select Page "Xuong Bom MINI" and obtain a Page
access token for Messenger and Page APIs.

D3e — pages_read_engagement

Used to list posts on our own Page so we can find comments that still need a
one-time Messenger private reply with an order button. We do not access other
Pages' content (no Page Public Content Access).

D3f — pages_read_user_content

Used to read comments written by people on our own Page posts, then send a
single Messenger private reply (not a public comment). Allowed usage: content
on Pages we manage only.
