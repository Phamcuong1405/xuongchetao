What the app does

  1. Customer messages the Page → automated greeting + order button (pages_messaging).
  2. Customer comments on a Page post → one-time Messenger private reply with the same order button (pages_read_engagement, pages_read_user_content, pages_messaging).
  3. Customer submits name / phone / address → COD order in FBAUTO.

Test steps for reviewers

  1. Use a Facebook user who is an Admin, Developer, or Tester of this app (Development mode).
  2. Open Messenger and message Page Xưởng Bơm MINI with any product question (example: “xin giá”).
  3. Expect an automated reply with an order button / order link within the 24-hour messaging window.
  4. Open the order link, enter a test name, phone, and address, submit.
  5. Comment on any post of the Page. Expect a one-time private reply on Messenger (not a public comment reply spam).

We do not send promotional blasts. We do not use HUMAN_AGENT in this submission. We only message people who messaged or commented on our Page.
